Todos os eventos têm o mesmo envelope. O pagamento completo vem em `data.object`.

```json
{
  "id": "evt_...",
  "object": "event",
  "type": "payment.succeeded",
  "livemode": true,
  "created": "2026-11-14T15:02:11.000Z",
  "data": { "object": { "id": "pay_...", "object": "payment", "status": "succeeded" } }
}
```

## Pagamentos

| Evento | Quando chega | Status do pagamento |
| - | - | - |
| `payment.succeeded` | o pagamento foi confirmado (Pix, cartão aprovado ou boleto pago) | `succeeded` |
| `payment.failed` | o cartão foi recusado ou a cobrança não pôde ser criada | `failed` |
| `payment.expired` | o Pix ou o boleto venceu sem pagamento | `expired` |
| `payment.canceled` | a cobrança foi cancelada antes do pagamento | `canceled` |
| `payment.refunded` | parte ou todo o valor foi devolvido ao pagador | `partially_refunded` ou `refunded` |
| `payment.disputed` | o comprador contestou a compra no cartão | `disputed` |
| `payment.dispute_won` | a contestação terminou a seu favor | `succeeded` |
| `payment.dispute_lost` | a contestação terminou a favor do comprador | `refunded` |

Use `"*"` em `events` para receber todos, inclusive os que forem criados no futuro.
