## Encontrando sua chave de API

Na Valora, as chaves de API são vinculadas a sua conta. Uma chave de API é gerada automaticamente assim que você cria sua conta. Para encontrar sua chave:

<Steps>
  <Step title="Faça login no Dashboard">
    Acesse o [Dashboard da Valora](https://docs.valora.cash) e faça login.
  </Step>
  <Step title="API aberta e webhooks">
    Acesse a seção API e Webhooks na barra lateral esquerda.
  </Step>
  <Step title="Copie suas chaves">
    Sua chave de API e chave secreta do webhook serão exibidas aqui. Copie-as conforme necessário.
  </Step>
</Steps>

<Card title="Sua chave de API é um segredo — trate-a como uma senha." type="warning">
  Ela fornece acesso total à API em nome da sua aplicação. Nunca a exponha no código do frontend, em repositórios públicos ou em pacotes do lado do cliente. Mantenha-a sempre restrita ao lado do servidor.
</Card>

## Fazendo solicitações autenticadas

Para autenticar uma solicitação de API, inclua sua chave secreta de API no `x-api-key`cabeçalho HTTP.Segue um exemplo de uma requisição autenticada para o `Pix `endpoint:

<RequestExample>

```shellscript cURL
curl --request POST \
     --url https://prod.api.valora.cash/v1/pixQrCode/ \
     --header 'accept: application/json' \
     --header 'content-type: application/json' \
     --header 'x-api-key: YOUR_API_KEY' \
     --data '
{
  "amount": "1",
}
```

</RequestExample>

## Tratamento de erros

Se a sua chave de API estiver ausente ou for inválida, a API retornará a `401 Unauthorized`seguinte resposta:

```json
{ 
	"detail": "Invalid or missing API key"
}
```

<Card type="tip">
  Se você receber um `401` erro, verifique novamente se está usando a chave de API correta para o aplicativo certo e se ela não foi regenerada.
</Card>
