## O que é Valora Payments?

A Valora Payments é a plataforma completa para lançar, escalar e monetizar seu negócio globalmente. Projetada para a nova geração de produtos digitais SaaS e de IA, gerenciamos tudo, desde pagamentos e faturamento até distribuição, sem a necessidade de engenharia adicional.

## Guia de Início Rápido

Comece a usar a Valora Payments em apenas alguns passos.

<Steps>
  <Step title="Crie sua conta">
    Cadastre-se em [dash.valora.cash](http://dash.valora.cash) usando seu e-mail.
  </Step>
  <Step title="Acesse a seção de Integração">
    Inicie a criação de uma nova chave de API
  </Step>
  <Step title="Configure o webhook e copie a chave da API.">
    Acesse a seção **API e Webhooks** na barra lateral:

    1. Adicione o URL do seu Webhook — a Valora envia atualizações de status aqui.
    2. Copie sua chave de API — mantenha-a apenas no servidor, nunca a exponha no código do frontend.
  </Step>
  <Step title="APIs independentes">
    Acesse os endpoints diretamente do seu backend.

    | Ponto final | Propósito |
    | --- | --- |
    | `POST /v1/pixQrCode/` | Para a criação de transações Pix |
    | `GET /v1/pixQrCode/[txid]/` | Para verificações de informações de transações Pix |
    | `GET /v1/coins/list/` | Informações de quais crypto ativos estão disponíveis para transações crypto |
    | `POST /v1/coins/sol/` | Criar transações crypto de Solana |
    | `POST /v1/coins/sol/[asset]/` | Criar transações crypto em token espeicfico da rede solana |
    | `GET /v1/coins/sol/[asset]/[reference]/` | Buscar informações de uma transação crypto |
  </Step>
  <Step title="Receba resultados em tempo real">
    A Valora envia eventos de webhook para o seu endpoint — sem necessidade de polling.

    | Evento | Acionar |
    | --- | --- |
    | <h3>`payment.confirmed`</h3> | Disparado quando um pagamento é confirmado — tanto Pix quanto Crypto |
    | `payment.expired` | Disparado quando um pagamento expira |
    | `payment.created` | Disparado quando um pagamento é criado |
    | `payment.failed` | Disparado quando um pagamento |
  </Step>
</Steps>
