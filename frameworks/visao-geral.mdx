## Antes de começar

Todos os tutoriais usam as mesmas três variáveis de ambiente:

```bash .env
VALORA_API_KEY=sk_vl_...          # Desenvolvedores → Chaves de API
VALORA_WEBHOOK_SECRET=whsec_...   # aparece ao criar o webhook
VALORA_PRODUCT_ID=prod_...        # produto ativo que você vai vender
```

<Steps>
  <Step title="Crie a chave de API">
    No painel, em **Desenvolvedores → Chaves de API**, crie uma chave com as permissões `checkouts:write` e `payments:read`.
  </Step>
  <Step title="Crie um produto">
    No painel, em **Produtos**, ou com [`POST /v1/products`](/api-reference/produtos/criar-um-produto). Copie o id (`prod_...`).
  </Step>
  <Step title="Exponha o servidor local">
    O webhook precisa de uma URL pública com HTTPS. Em desenvolvimento, use um túnel:

    ```bash
    ngrok http 3000
    ```
  </Step>
  <Step title="Cadastre o webhook">
    Em **Desenvolvedores → Webhooks → Adicionar destino**, informe `https://SEU-TUNEL/api/webhooks/valora` (o caminho do tutorial) e guarde o segredo `whsec_...`.
  </Step>
</Steps>
