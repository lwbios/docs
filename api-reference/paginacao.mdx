---
title: "Paginação"
description: "Percorra listas com cursor usando limit e starting_after."
icon: "list-ol"
---

As rotas de lista (`GET /v1/payments`, `GET /v1/customers`, `GET /v1/products`, `GET /v1/webhooks/{endpoint_id}/deliveries`) devolvem os itens do mais novo para o mais antigo, em páginas.

## Parâmetros

| Parâmetro | Descrição |
| - | - |
| `limit` | itens por página, de 1 a 100. Padrão: 20 |
| `starting_after` | o `next_cursor` da página anterior |

## Resposta

```json
{
  "object": "list",
  "data": [{ "id": "pay_...", "object": "payment" }],
  "has_more": true,
  "next_cursor": "eyJ0IjoxNzYzMTMyOTMxMDAwLCJpZCI6InBheV8uLi4ifQ"
}
```

Enquanto `has_more` for `true`, peça a próxima página passando `next_cursor` em `starting_after`.

```js
let cursor = null;
do {
  const url = new URL("https://api.valorapayments.com.br/v1/payments");
  url.searchParams.set("limit", "100");
  url.searchParams.set("status", "succeeded");
  if (cursor) url.searchParams.set("starting_after", cursor);

  const page = await fetch(url, { headers: { Authorization: `Bearer ${process.env.VALORA_API_KEY}` } }).then((r) => r.json());
  for (const payment of page.data) {
    // processe o pagamento
  }
  cursor = page.has_more ? page.next_cursor : null;
} while (cursor);
```

<Note>
  O cursor é opaco: não monte nem altere. Mantenha os mesmos filtros entre as páginas.
</Note>
